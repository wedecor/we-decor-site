Written 8 Nov 2026. This is the measurement plan for visibility in Google AI
Overviews, ChatGPT Search, Gemini and Perplexity. It does not promise that
any of them will recommend the business. It sets a baseline, a monthly
routine, and the GA4 configuration that makes AI referrals visible.

## 2. Monthly benchmark — 12 queries

Run on the first weekday of each month. Use a logged-out browser or a fresh
account for each engine, Bengaluru location set where the engine allows it.
Ask the query verbatim. Record the result in the table (copy the template
into `docs/ai-benchmarks/YYYY-MM.md`; do not edit this file's template).

Engines: **Google AI Overview** (google.com, note whether an AI Overview
appeared at all), **ChatGPT** with search on, **Gemini**, **Perplexity**.

Columns per engine:

- **Mentioned** — business named anywhere in the answer (Y/N)
- **Recommended** — named as a recommendation, not just listed (Y/N)
- **Cited** — `wedecorevents.com` appears as a source/link (Y/N) and which
  URL
- **Competitors named** — list
- **Accurate** — are the price, locality, services, phone correct? Note any
  error verbatim (this is the thing to fix on the site)
- **Page cited** — which service or locality page, if any

Interpretation rules:

- Queries 4 and 11 are proximity queries. Engines answer them from the map
  pack, i.e. from GBP. A miss there is a GBP problem, not a website problem.
- Queries 9 and 10 should cite `/locations/jayanagar` and
  `/locations/whitefield`. If they cite the homepage instead, the locality
  page is not being read as the canonical answer for that locality — look
  at the FAQ and body copy on that page.
- Query 8 should surface the ₹3,000 floor. If an engine quotes a different
  price, find where it got it (old GBP services, Justdial, a cached page)
  and fix the source.
- Query 12 is the one the site does not target. Do not add “premium” copy
  to chase it; note it and move on.
- Accuracy errors are the highest-value finding each month. An engine that
  mentions the business with a wrong phone number is worse than one that
  does not mention it.

## 3. GA4 — making AI referrals visible — NEEDS OWNER ACTION

GA4 already receives traffic from GTM `GTM-K46BR4ZT` → `G-6L9VRFJ4Q5`
(production only; `isAnalyticsEnabled()` is false elsewhere). AI engines
send normal HTTP referrers, so no code change is required. Configure it in
the GA4 admin:

1. **Admin → Data display → Channel groups → create a custom channel group**
   (“Default + AI”). Add a channel **“AI Search”** above “Referral” with the
   rule: _Source matches regex_
   `chatgpt\.com|openai\.com|perplexity\.ai|gemini\.google\.com|copilot\.microsoft\.com|claude\.ai|you\.com|bing\.com/chat`.
   Keep everything else as default.
2. **Admin → Data display → Channel groups**: GA4 may bucket some AI
   referrers as “Organic Search” or “Referral”. The custom group above
   overrides that for reporting without changing the stored data.
3. **Explore → free-form**: dimension _Session source / medium_, metrics
   _Sessions_, _Key events_ (`generate_lead`, `whatsapp_click`,
   `phone_click`). Filter by the AI Search channel. Save as “AI referrals”.
4. **Monthly export**: sessions, engaged sessions, `whatsapp_click`,
   `phone_click`, `generate_lead` for the AI Search channel. Record them in
   the same `docs/ai-benchmarks/YYYY-MM.md` file as the query table.
5. Optional: GTM variable _Referrer_ → GA4 event parameter `page_referrer` is
   already sent automatically; no custom tag is needed.

Caveats to write down so nobody misreads the numbers later:

- ChatGPT sometimes strips the referrer; expect under-counting.
- Google AI Overview clicks arrive as `google / organic` and are
  indistinguishable from classic organic in GA4. Search Console does not
  break them out either (as of Nov 2026). The only signal is a CTR shift on
  question-style queries.
- Perplexity and Gemini traffic will be tiny for a local service business.
  Twenty sessions a month would be a good result; judge direction, not
  magnitude.

## 4. Search Console — what to watch alongside

- Performance → Queries filtered to “near me”, “best”, “how much”, “cost”:
  these are the queries AI Overviews most often answer. Falling impressions
  with stable position means AIO is absorbing the click.
- Performance → Pages → `/faq`: this page now carries the eight
  highest-intent questions. Rising impressions here after late Nov 2026 is
  the first expected signal.
- Enhancements → FAQ / Breadcrumbs / Sitelinks searchbox: keep at zero
  errors. The jsonld test suite guards structure; GSC confirms Google read it.

## 5. Bing / Copilot — NEEDS OWNER ACTION

ChatGPT Search and Copilot both lean on Bing's index. Add the site to Bing
Webmaster Tools (import from Search Console is a one-click option), submit
`https://www.wedecorevents.com/sitemap.xml`, and check IndexNow is **not**
needed (Vercel does not emit it; manual submission is fine at 90 URLs).

## 6. Owner routine (30 minutes a month)

1. Run the 12 queries × 4 engines; fill the table.
2. Export the GA4 “AI referrals” exploration.
3. Note any factual error an engine made and fix its source (site, GBP, or
   a third-party listing).
4. Update `GOOGLE_REVIEW_COUNT` if Places moved.
5. File as `docs/ai-benchmarks/YYYY-MM.md`.
